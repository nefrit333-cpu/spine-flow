# PRD-000: Spine Flow

## Назначение

Spine Flow - бесплатное iPhone-first веб-приложение с короткими практиками йоги для комфортного восстановления после сидячей работы. Цель первого релиза - опубликовать сервис по HTTPS, чтобы пользователь мог добавить его на экран «Домой» в Safari и запускать как отдельное приложение.

## Границы MVP

- Платформа: iPhone и Safari.
- Интерфейс и контент: русский язык.
- Пять встроенных практик: для шеи, плеч, поясницы, после рабочего дня и вечернего расслабления спины.
- Прохождение практики по карточкам поз с таймером, паузой и ручными переходами.
- Локальное сохранение последней практики и числа завершённых занятий.
- Приложение бесплатно: без аккаунта, backend-сервера, рекламы, покупок и подписок.
- Сервис работает только при подключении к интернету; offline-кеш не входит в MVP.

## Позиционирование

Приложение относится к wellness-категории. Оно помогает сделать мягкую практику после рабочего дня, но не диагностирует и не лечит заболевания. Перед первой практикой показывается краткое предупреждение: при боли, травме или ухудшении самочувствия практику следует прекратить и обратиться к специалисту.

## Успех первого релиза

Пользователь может открыть сервис по HTTPS в Safari, добавить его на экран «Домой», выбрать любую из пяти практик, пройти её онлайн и вернуться к главному экрану с обновлённым локальным прогрессом.
