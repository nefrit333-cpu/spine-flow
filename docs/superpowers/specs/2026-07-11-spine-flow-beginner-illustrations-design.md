# Spine Flow - цветные иллюстрации начинающего уровня

## Цель

Заменить универсальные line-art изображения в практиках начинающего уровня на отдельные цветные editorial-иллюстрации. Каждый экран упражнения должен показывать молодую спортивную девушку в позе, точно соответствующей текущей инструкции.

## Визуальное направление

- Премиальная wellness-иллюстрация в стиле карточек выбора сложности.
- Молодая совершеннолетняя спортивная девушка в сдержанной современной спортивной одежде.
- Светлый студийный фон с мягкими оттенками sage, coral, blue или lilac в соответствии с практикой.
- Полная фигура или композиция, достаточная для ясного показа движения; без текста, логотипов, медицинских символов и инвентаря, кроме стены для отжиманий.
- Вертикальный кадр 3:4, рассчитанный на крупное отображение в блоке упражнения через существующий `object-fit: cover`.
- Все изображения хранятся локально в `web/public/images`.

## Данные и отображение

- Повторяющиеся ID (`start`, `rest`, `turn`, `breath`) заменяются перечисленными уникальными ID только в практиках начинающего уровня.
- Средняя практика, её ID и её изображения не меняются.
- `PoseIllustration` получает полное явное сопоставление всех уникальных ID с путями изображений; fallback сохраняется только как защита от неизвестных данных.
- `PracticePage` не меняет пользовательскую механику таймера, паузы, переходов, завершения и сохранения прогресса.

## Тестирование и приёмка

1. Каталог сохраняет пять практик начинающего и одну среднюю, при этом ID каждого шага уникален во всём каталоге.
2. Каждый уникальный ID начинающего уровня имеет локальный PNG и точное сопоставление в `PoseIllustration`.
3. E2E проходит все этапы каждой начальной практики и проверяет `src` изображения после каждого перехода.
4. Средняя практика продолжает показывать свои девять изображений без регрессии.
5. На ширине 375 px изображение и текст упражнения остаются видимыми, не перекрываются и не обрезаются.
6. Интерфейс не получает аккаунтов, backend, нового уровня сложности, уведомлений или медицинских утверждений.
