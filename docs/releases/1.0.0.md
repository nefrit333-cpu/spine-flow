# Spine Flow 1.0.0

Дата релиза: 18 июля 2026

## Состав релиза

- iPhone-ориентированное PWA с запуском из Safari и установкой через "На экран Домой".
- Выбор тренера: девушка или парень; изображения практик соответствуют выбранному персонажу.
- Практики начального и среднего уровня с подготовкой, упражнениями, завершением и пошаговым таймером.
- Экран завершения практики и локальный учёт прогресса.
- Настройки, смена персонажа, поддержка, политика конфиденциальности и удаление локальных данных.
- Hash-навигация для прямых ссылок, обновления страницы и кнопки "Назад" браузера.
- Учёт верхней safe area iPhone на экране практики.

## Проверка релиза

- Модульные тесты: 30 успешно пройденных тестов.
- Сквозные тесты Playwright: 13 успешно пройденных сценариев.
- Производственная сборка Vite выполнена успешно.
- PWA проверено на реальном iPhone после установки через Safari: приложение открывается без адресной строки, экран практики не пересекается с системной строкой состояния.

## Ограничения

- Для загрузки контента требуется интернет.
- Данные прогресса и настройки хранятся только в браузере устройства.
- Нативные сборки для iOS и Android, а также публикация в App Store не входят в этот релиз.
- Упражнения не являются медицинской рекомендацией.
