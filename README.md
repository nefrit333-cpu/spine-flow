# Spine Flow

**Spine Flow** - русскоязычное PWA для коротких практик на подвижность, шею, плечи и спину. Интерфейс рассчитан прежде всего на iPhone: сайт можно добавить на экран "Домой" через Safari и запускать в полноэкранном режиме, как приложение.

Публичная версия: [spine-flow-yoga.vercel.app](https://spine-flow-yoga.vercel.app)

## Что есть в актуальной версии

- Выбор тренера: девушка или парень.
- Практики начального и среднего уровня с пошаговым таймером.
- 15-минутная динамическая разминка в спортзале без инвентаря: 15 упражнений для шеи, плеч, рук, груди, спины, таза и ног.
- Визуальные инструкции и текстовое сопровождение каждого упражнения.
- Локальное сохранение выбранного тренера, прогресса и подтверждения правил безопасности.
- Экран настроек, поддержка и политика конфиденциальности.
- Навигация по ссылкам и корректная работа системной кнопки "Назад" в браузере.

Приложение не требует регистрации, не показывает рекламу и не передаёт прогресс на сервер. Для работы требуется подключение к интернету.

## Установка на iPhone

1. Откройте публичную ссылку в Safari.
2. Нажмите кнопку "Поделиться" в нижней панели браузера.
3. Выберите "На экран Домой".
4. Откройте Spine Flow с созданного значка.

После установки Safari не показывает адресную строку, а приложение запускается в отдельном окне.

## Локальный запуск

Требуется Node.js 20 или новее.

```powershell
cd web
npm.cmd install
npm.cmd run dev
```

Vite выведет локальный адрес для открытия в браузере.

## Проверки

Из каталога `web`:

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run test:e2e
```

## Структура репозитория

- `web/` - исходный код React/Vite PWA, тесты, PWA-манифест и оптимизированные изображения, необходимые приложению.
- `docs/releases/` - заметки к опубликованным версиям.
- `README.md` - запуск, установка и состав продукта.

Локальные кэши, `node_modules`, результаты сборки и исходные PNG-мастера изображений не входят в Git-репозиторий. В репозитории уже есть оптимизированные WebP-файлы, которые использует приложение.
