# Вклад в Spine Flow

Spine Flow - публичный репозиторий с закрытым режимом использования исходников и материалов. Перед предложением изменений ознакомьтесь с [LICENSE.md](LICENSE.md). Для уязвимостей действует отдельная [Security Policy](SECURITY.md).

## Как предложить изменение

Используйте шаблоны GitHub Issues:

- **Bug report** - если поведение отличается от ожидаемого;
- **Feature request** - если предлагаете функцию или улучшение;
- **Task** - если хотите оформить конкретную техническую задачу.

Перед Pull Request создайте отдельную ветку от актуальной основной ветки. Один Pull Request должен решать одну понятную задачу и содержать краткое описание изменений и проверки.

## Требования к изменениям

- Не добавляйте ключи, токены, персональные данные, `node_modules`, сборки и временные файлы.
- Сохраняйте iPhone-first интерфейс и русский язык пользовательского текста.
- Для изменений кода запускайте из `web/`: `npm.cmd test`, `npm.cmd run build` и, когда сценарий затронут, `npm.cmd run test:e2e`.
- Добавляйте только материалы, на которые у вас есть права. Не используйте чужие изображения, тексты или бренды без разрешения.
- Не добавляйте медицинские обещания и не представляйте практики как замену консультации специалиста.

## Права на вклад

Отправляя Pull Request, вы подтверждаете, что имеете право передать его содержание. Вы предоставляете автору проекта неисключительное, безвозмездное, бессрочное и всемирное право использовать, изменять, публиковать и распространять ваш вклад как часть Spine Flow, включая сублицензирование в составе проекта. Если эти условия вам не подходят, не отправляйте Pull Request.

Автор проекта может принять, отклонить или доработать любой вклад. Отправка Issue или Pull Request не создаёт обязательства по его включению.
